# Лабораторная работа: TextInput

## Цель
Научиться работать с текстовым полем ввода
и управлять его значением через useState.

## Задание
Создать экран с полем ввода имени пользователя.

## Требования
- Использовать компонент TextInput.
- Хранить введённый текст в состоянии name.
- Связать value с состоянием name.
- Использовать onChangeText для изменения состояния.
- При вводе имени показывать приветствие.
