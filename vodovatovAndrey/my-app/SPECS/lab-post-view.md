# Лабораторная работа: просмотр одного поста

## Цель
Научиться получать отдельный объект с сервера
по его идентификатору.

## Задание
Создать экран PostViewScreen для просмотра поста.

## Требования
- Открывать экран нажатием на карточку.
- Передавать ID выбранного поста через навигацию.
- Получать пост через функцию getPost из api.ts.
- Выполнять запрос в useEffect с зависимостью [id].
- Отображать заголовок, полный текст и дату.
- Показывать индикатор загрузки.
- Обрабатывать ошибки и отсутствие поста.
- Предусмотреть возврат к списку.
