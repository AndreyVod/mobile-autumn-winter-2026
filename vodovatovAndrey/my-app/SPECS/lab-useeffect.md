# Лабораторная работа: useEffect

## Цель
Научиться использовать useEffect для выполнения
действий после отображения компонента.

## Задание
Создать экран с имитацией загрузки данных.

## Требования
- Использовать useEffect и useState.
- При открытии экрана показывать загрузку.
- Через 2 секунды отображать три элемента.
- Использовать setTimeout для задержки.
